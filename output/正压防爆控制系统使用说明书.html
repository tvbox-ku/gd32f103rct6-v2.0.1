一、产品概述

本系统是一套正压防爆电气控制装置，用于对防爆柜体进行正压维持、换气吹扫、欠压断电保护，并对柜内压力、温度以及柜体流失流量进行实时监测与显示。系统采用 3.5 寸彩色触摸显示屏，通过 3 个实体按键完成全部操作。

主要功能

  • 柜内压力、温度实时监测与显示；
  • 进气 / 排气继电器自动稳压控制（维持柜内正压）；
  • 换气吹扫倒计时；
  • 欠压延时自动切断送电（防爆安全保护）；
  • 超压、欠压、超温、传感器故障声光报警；
  • 压力衰减法测量柜体流失流量（30s 自动滚动测量）；
  • 参数、密码、校准数据掉电保存（内置 Flash）。

五、操作指南

5.1 开机

接通电源，系统上电自检并显示开机动画（约 3 秒），随后进入主页面。屏幕长时间无操作会进入息屏，按任意键唤醒。

5.2 正压启动

图 5-1　正压启动流程

操作步骤：

  1. 在主页面按 KEY1（正压启动）；
  2. 系统进入换气倒计时（默认 900 秒），期间自动控制进 / 排气阀对柜体进行吹扫换气；
  3. 倒计时结束且柜内压力达到设定正常范围后，系统自动送电接通负载；
  4. 进入「系统运行中」状态，持续稳压、报警监测，并每隔 30 秒自动测算流失流量；
  5. 运行中按 KEY3 可返回主页，按 KEY1 可对报警进行消音。

5.3 系统设置

  1. 主页面按 KEY2，输入密码（默认 555）后进入设置菜单；
  2. 按 KEY2 移动选中项，按 KEY3 进入；
  3. 按 KEY1 可返回主页。

5.4 修改密码

  1. 进入「修改密码」，用 KEY1 加值、KEY2 移动位、KEY3 确认；
  2. 长按 KEY3 保存，长按 KEY1 返回。

5.5 校准传感器

在「校准传感器」中可分别校准温度和压力显示值：

  1. 按 KEY1 加减数值、KEY2 移位、KEY3 切换校准项；
  2. 长按 KEY3 保存校准结果，长按 KEY2 放弃修改。

5.6 设置参数

可设置以下 8 项参数（单位见「参数说明」）：

压力下限 → 压力下下限 → 压力上限 → 压力上上限 → 温度上限 → 换气时间 → 流量量程 → 柜体容积

操作：KEY1 加值、KEY2 移位、KEY3 切换下一项；长按 KEY3 保存，长按 KEY2 放弃。

5.7 系统调试

危险！调试模式会在现场直接送电，请务必确认危险区域无人、环境安全后方可操作。
  1. 主页面按 KEY3，输入密码进入调试页；
  2. 阅读红色安全提示后，按 KEY3（确认调试）；
  3. 系统强制送电，屏幕显示实时压力、温度；
  4. 调试完毕按 KEY3（调试结束） 退出。

七、流失流量监测说明

流失流量用于量化柜体的密封性 / 泄漏程度，采用压力衰减法测量：

  • 测量时机：仅在柜体处于稳定状态（进 / 排气阀都关闭）时自动进行，不影响正常稳压；
  • 测量周期：每 30 秒自动结算并刷新一次；
  • 计算方式：
流失流量(L/h) = 8.275 × 压降(Pa) / 时间(s) × 293.15 / (273.15 + 柜温℃)
  • 温度修正：使用 PT100 实测柜温自动修正（工作温度 -50~120℃）；
  • 前提：计算结果依赖于柜体密闭容积，该容积可在「系统设置 → 设置参数 → 柜体容积」中按实际柜体填写（单位 L，默认 250L = 0.25 m³）；若测量期间柜门开启，结果会偏差。

情况动作

温度 / 压力传感器断线或超程声光报警
换气时间内压力不能恢复压力恢复超时报警

报警解除后，蜂鸣器可按 KEY1 消音；故障排除且参数恢复正常后报警自动复位。

九、安全须知

  1. 本设备属于防爆场合用电气装置，安装、接线、调试必须由具备相应资质的专业人员进行；
  2. 设备通电运行前，确认柜门关闭、防爆面完好、所有紧固件齐全；
  3. 系统处于报警或欠压断电状态时，应先排查故障原因，严禁直接屏蔽报警继续使用；
  4. 压力、温度传感器量程应与柜体实际工况匹配；
  5. 更改参数、密码后请核对无误再投入运行，重要参数改动可能影响防爆保护功能。
